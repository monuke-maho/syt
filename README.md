## 機能

### ダウンロード機能

`yt-dlp`を使用して動画をダウンロード可能です。  
当アプリがサポートしているサイトはYouTube, YouTube Musicです。

### 動画・音声形式の選択

動画ならmp4,mkvから、音声ならmp3,flac,wavから選択可能です。

### 画質・音質の選択

動画なら720p~4Kを、音声(mp3のみ)なら128kbps~320kbpsを選択可能です。  
もちろん自動選択もあります。

### ブラウザーからのcookie読み込み

Firefoxベースのブラウザからプロファイルを取得し、選択することでそのプロファイルにあるcookieを使用することができます。  
現在対応しているブラウザはFirefox,Floorp,Zen,Librewolfです。

また手動でプロファイルパスを入力することも可能です。

> [!NOTE]
> Linuxなどではインストール方法によってはプロファイルを検出できない可能性があります。

### 実用的なファイル命名

デフォルトで`<タイトル>.<拡張子>`です。  
プレイリストモードを有効にすると`<プレイリストの名前>/<タイトル>.<拡張子>`になり、  
加えてインデックスを付与を有効にすると`<プレイリストの名前>/<プレイリストのインデックス> - <タイトル>.<拡張子>`のようになります。

### メタデータ・サムネイル

メタデータを埋め込むか否かを選択できます。  
またサムネイル埋め込みも可能で、サムネイルは1:1にクロップするオプションがあります。

### アルバムモード
YouTube Musicからのダウンロードに便利なモードです。  
ファイル命名が`<アルバムのタイトル>/<トラック番号> - <タイトル>.<拡張子>`のようになり、  
メタデータをパースし適切に埋め込み、サムネイルを1:1にクロップまでを一つのスイッチで有効にできます。

### yt-dlpの自動更新

起動時にyt-dlpの更新処理を行います。  
設定で無効にできますが、エラーを防ぐため定期的に更新を行なってください。
